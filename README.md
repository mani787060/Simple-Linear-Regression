# Simple Linear Regression in Machine Learning

## 📌 Project Overview

This project demonstrates the implementation of **Simple Linear Regression**, one of the most fundamental supervised machine learning algorithms used for predicting continuous numerical values.

Using the **cgpa_placement.csv** dataset, the notebook explores the relationship between a student's CGPA and placement package, helping understand how a single independent variable can be used to predict a target variable.

---

## 🎯 Objectives

* Understand the concept of Simple Linear Regression
* Learn the relationship between independent and dependent variables
* Build a regression model for prediction
* Visualize the best-fit regression line
* Evaluate model performance using regression metrics

---

## 📂 Dataset

**Dataset Used:** `cgpa_placement.csv`

The dataset contains information about students' CGPA and corresponding placement packages, which is used to build and evaluate a simple regression model.

## ⚙️ Implementation Steps

### Data Exploration

* Load and inspect the dataset
* Understand feature relationships
* Visualize data using scatter plots

### Model Building

* Split data into training and testing sets
* Train the Linear Regression model
* Learn slope and intercept values

### Prediction

* Generate predictions on test data
* Plot the regression line

### Model Evaluation

* Calculate R² Score
* Calculate Mean Absolute Error (MAE)
* Calculate Mean Squared Error (MSE)
